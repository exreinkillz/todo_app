## To-Do CLI App (Python)

A simple command-line To-Do Application written in Python
This project was built to practice core Python concepts such as functions,dictionaries,file handling,and basic program structure.


## Features

- Add new tasks
- List all tasks
- List completed tasks only
- Toggle task status (done / pending)
- Edit existing tasks
- Delete tasks
- View task statistics (completion rate, pending tasks)
- Persistent storage using JSON

## Technologies

- Python 3
- JSON for data persistence

## How to Run

1. Clone the repository
2. Make sure Python 3 is installed
3. Run the application:

```bash
python todo_app.py
